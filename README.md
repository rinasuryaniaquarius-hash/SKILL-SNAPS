# SKILL-SNAPS
SNAPS — Skills Network &amp; Professional Services adalah platform digital tempat orang dapat mendaftarkan keterampilan yang mereka miliki. Pengguna lain dapat mencari keterampilan tertentu berdasarkan kategori dan lokasi, melihat profil pemilik skill, melihat portofolio dan rating, kemudian menghubungi mereka untuk menggunakan jasanya.
